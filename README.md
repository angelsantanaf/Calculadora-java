# 🧮 Calculadora em Java

Projeto desenvolvido em **Java** com o objetivo de aplicar conceitos de lógica de programação e operações matemáticas.

## 📌 Sobre o projeto

A calculadora permite realizar operações matemáticas de forma simples, utilizando conceitos fundamentais aprendidos durante os estudos de programação.

## ⚙️ Funcionalidades

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão

## 🛠️ Tecnologias utilizadas

- Java
- Lógica de Programação

## 🎯 Objetivo

Praticar e aprimorar conhecimentos em Java, trabalhando com entrada de dados, operadores matemáticos e estruturas de decisão.
